# 项目复盘专题

## 收录范围

完整项目、阶段性改造、系统能力建设、从目标到验证的闭环复盘。

## 不收录范围

零散任务记录、没有明确结果的尝试、未完成且无法总结的过程。

## 推荐文章类型

项目复盘、架构决策记录、阶段总结。

## 推荐 tags

`Project Review`、`Retrospective`、`Architecture`、`Delivery`
