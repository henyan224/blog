# 经验教训专题

## 收录范围

故障排查、踩坑复盘、错误日志分析、失败原因与防复发措施。

## 不收录范围

没有根因分析的抱怨、无法复现的问题、只对单次会话有效的临时记录。

## 推荐文章类型

踩坑记录、项目复盘、排查手册。

## 推荐 tags

`Lessons`、`Troubleshooting`、`Debugging`、`Postmortem`

## 正式文章目录

```text
src/content/blog/lessons/
```

## 示例标题

- Bun test 卡住如何定位
- Astro 文章移动后为什么 URL 会变化
- PowerShell 不支持 && 的排查记录
