# Notes

`notes/` 是未发布知识草稿区，不参与 Astro 内容集合构建。

## 目录

- `inbox/`：临时输入箱，存放零散材料。
- `logicai/`：LogicAI2 任务沉淀草稿。
- `reviews/`：项目复盘草稿。
- `lessons/`：踩坑与经验教训草稿。

## Git 策略

- `notes/` 可以纳入 Git 管理。
- README 和已脱敏示例可以提交。
- 真实草稿默认不得直接提交。
- 真实草稿提交前必须经过萧何敏感信息审计。
- 含密钥、账号、私有服务地址、代理配置、未公开业务细节的草稿不得 push 到 GitHub。

## 发布边界

这里的文件不是正式文章。正式文章只能进入 `src/content/blog/{topic}/`，并必须通过构建验证。
