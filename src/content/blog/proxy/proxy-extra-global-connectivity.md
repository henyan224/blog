## 第一章：SIM 卡的本质

### 传统 SIM 卡

你手机里那张小塑料卡，本质上是一个**微型安全芯片**，里面存着：

```
SIM 卡里有什么？

├── IMSI（国际移动用户识别码）
│     → 你在运营商那边的"身份证号"
│     → 格式：460 01 1234567890
│              ↑    ↑
│            国家码  运营商码（01=联通，00=移动，11=电信）
│
├── Ki（认证密钥）
│     → 和运营商共享的加密密钥
│     → 手机开机时，用这个密钥和基站"对暗号"
│     → 对上了才允许你接入网络
│
├── ICCID（卡片序列号）
│     → 这张卡的物理编号
│
└── 运营商配置
      → APN（接入点）、网络优先级等
```

> **SIM 卡的安全核心是 Ki 密钥**——它在出厂时烧录进芯片，无法被读取或复制。运营商的服务器也存着同一个 Ki。每次你的手机连接基站，双方用 Ki 做一次加密挑战-应答认证（类似我们之前讲的 Reality 握手），通过了才让你上网。

### SIM 卡的进化

```
Full-size SIM    Mini-SIM      Micro-SIM     Nano-SIM      eSIM
(1991, 信用卡大小) (1996)        (2010, iPhone 4) (2012, iPhone 5) (2016, 内置芯片)
 ┌──────────┐   ┌─────┐       ┌───┐         ┌──┐          [焊在主板上]
 │          │   │     │       │   │         │  │          无需插拔
 │   芯片   │   │ 芯片│       │芯 │         │芯│          软件写入
 │          │   │     │       │片 │         │片│
 └──────────┘   └─────┘       └───┘         └──┘
```

每一代都在缩小物理尺寸，直到 eSIM——**彻底取消了物理卡片**。

## 第二章：eSIM 详解

### eSIM 是什么？

**eSIM（Embedded SIM，嵌入式 SIM）** = 一颗焊死在手机主板上的 SIM 芯片。它和传统 SIM 功能完全一样（存 IMSI、Ki、运营商配置），唯一区别是：**运营商信息通过网络下载写入，而不是出厂预烧录。**

```
传统 SIM：
  运营商 → 把信息烧录到塑料卡 → 快递给你 → 你插进手机 → 联网

eSIM：
  运营商 → 生成一个"配置文件"（QR码/App）→ 你扫码下载 → 写入内置芯片 → 联网
```

### eSIM 的优势

| 传统 SIM | eSIM |
|---------|------|
| 需要物理卡片 | 无需卡片，下载激活 |
| 一张卡 = 一个运营商 | 一个芯片可存 **8+ 个**运营商配置 |
| 换运营商 = 换卡 | 换运营商 = 下载新配置（几秒） |
| 出国 = 买当地 SIM 卡 | 出国 = 手机上买 eSIM 套餐 |
| 占用卡槽 | 不占卡槽，和实体卡共存 |

### 哪些设备支持 eSIM？

| 设备 | eSIM 支持 | 备注 |
|------|----------|------|
| **iPhone XS/XR 及之后** | ✅ | iPhone 16 美版已取消实体卡槽 |
| **iPad Pro/Air（WiFi+蜂窝版）** | ✅ | |
| **Apple Watch（蜂窝版）** | ✅ | 独立打电话/上网 |
| **Google Pixel 3 及之后** | ✅ | |
| **三星 Galaxy S20 及之后** | ✅ | |
| **华为（国行）** | ❌ | 国行大部分不支持 eSIM |

> **注意：中国大陆销售的部分手机会阉割 eSIM 功能。** 港版/美版/国际版通常完整支持。如果你用国行 iPhone，eSIM 功能可用但需要运营商配合（目前三大运营商对 eSIM 支持有限）。

### 一台手机能同时用几个号？

```
iPhone 15（举例）：

┌─────────────────────────────┐
│  实体 nano-SIM 卡槽: 1 个    │
│  eSIM 芯片: 可存 8+ 个配置    │
│                              │
│  同时激活: 最多 2 个号码       │
│    → 1 个用于通话/短信        │
│    → 1 个用于蜂窝数据         │
│    （可以都是 eSIM）           │
└─────────────────────────────┘

实际使用场景：
  实体卡: 中国移动（日常通话 + 国内流量）
  eSIM 1: Airalo 日本套餐（出差时切换到这个上网）
  eSIM 2: Google Fi 美国号（注册海外服务用）
  ↑
  三个号码都存在手机里，在设置中随时切换哪个用于数据
```

## 第三章：全球联网方案对比

### 方案一：eSIM 全球流量服务（最推荐）

通过 App 按国家/地区购买数据套餐，即买即用：

| 服务 | 覆盖 | 价格 | 特点 |
|------|------|------|------|
| **Airalo** | 200+ 国家 | $5/1GB 起 | 最主流，性价比高 |
| **Nomad** | 100+ 国家 | $5/1GB 起 | 界面好，支持分享 |
| **Holafly** | 170+ 国家 | $6/天起 | **不限流量**（可能限速） |
| **eSIMdb** | 比价平台 | — | 搜索最便宜的 eSIM 套餐 |

**使用流程：**

```
1. 下载 Airalo App（出发前）
2. 搜索目标国家（如"Japan"）
3. 选择套餐（如 1GB/7天/$4.5）
4. 付款（支持信用卡/PayPal）
5. 安装 eSIM（扫码或直接在 App 中安装）
6. 到达日本 → 设置中激活 → 自动连接当地运营商
7. 你的中国实体卡照常接电话
```

> **重要**：eSIM 安装需要网络连接。所以建议**出发前在有 WiFi 的时候就装好**，到了当地再激活。

### 方案二：Google Fi（频繁出国首选）

Google 的虚拟运营商，**一张卡全球 200+ 国家自动漫游**：

```
Google Fi 的工作方式：

在美国 → 自动连 T-Mobile / US Cellular
飞到日本 → 落地自动连 SoftBank / NTT DoCoMo
飞到英国 → 自动连 Three / EE
飞到尼日利亚 → 自动连 MTN / Glo

全程无需操作，和在美国用一模一样
```

| 套餐 | 月费 | 数据 | 适合 |
|------|------|------|------|
| Flexible | $20 + $10/GB | 按量付费 | 轻度使用 |
| Simply Unlimited | $50/月 | 无限（限速） | 日常出差 |
| Unlimited Plus | $65/月 | 无限 + 热点 | 重度用户 |

**Google Fi 的额外好处：**
- 给你一个**美国手机号**（+1 开头），注册各种海外服务很方便
- 支持 WiFi Calling（WiFi 环境下打电话）
- 支持 eSIM，不占实体卡槽

**缺点：**
- 需要美国地址激活（可以用转运地址）
- 在中国大陆可能被限速或不稳定
- 长期不在美国使用可能被限制服务

### 方案三：当地实体 SIM 卡（最便宜）

到了当地买一张预付费 SIM 卡，价格通常比 eSIM 便宜：

```
常见购买地点：
├── 机场到达大厅的运营商柜台
├── 便利店（日本 7-11、泰国 7-11）
├── 运营商营业厅
└── 自动售卖机（日本机场常见）
```

| 国家 | 推荐运营商 | 价格参考 |
|------|----------|---------|
| 日本 | IIJmio / Mobal | ¥50-100/7天 |
| 泰国 | AIS / True | ฿200-400/7天 |
| 美国 | T-Mobile / Mint | $15-30/月 |
| 英国 | Three / giffgaff | £10-20/月 |
| 新加坡 | Singtel / StarHub | S$12-30/7天 |

**缺点**：需要拔出中国 SIM 卡（除非你是双卡手机），语言障碍，有些国家需要护照实名。

### 方案四：国际漫游（最省事但最贵）

直接用中国号码的国际漫游功能，开通后出国自动连当地网络：

```
中国移动国际漫游数据流量：
  日本：30 元/天（不限量，超 200MB 限速）
  美国：30 元/天
  欧洲：30 元/天

或者买流量包：
  全球通用：68 元/500MB
```

> **贵且限速。** 只适合偶尔出国、嫌麻烦不想折腾的人。同样的钱，Airalo eSIM 能买 10 倍的流量。

### 方案五：Starlink 卫星互联网（极端场景）

SpaceX 的星链，**地球上有天空的地方就能上网**：

```
原理：
  你的设备 → Starlink 天线（便携锅盖）→ 低轨卫星 → 地面站 → 互联网

覆盖：全球（包括海上、沙漠、极地、丛林）
延迟：20-50ms（低轨卫星，不像传统卫星那么高延迟）
带宽：50-200Mbps
设备：便携天线 $599（可折叠，背包能装下）
月费：$120/月（Roam 漫游套餐，全球可用）
```

适合场景：
- 非洲/南美腹地科考
- 海上航行
- 偏远山区
- 灾难应急

## 第四章：推荐方案

### 按使用场景选择

```
偶尔出国旅游（一年 1-2 次）：
  └── Airalo eSIM
      每次 $5-15，用完就删
      推荐指数：⭐⭐⭐⭐⭐

频繁出差（每月出国）：
  └── Google Fi
      $50-65/月，全球自动漫游
      推荐指数：⭐⭐⭐⭐

长期海外生活：
  └── 当地实体 SIM + 中国号码保号套餐（8元/月）
      推荐指数：⭐⭐⭐⭐

偏远地区 / 极端环境：
  └── Starlink 便携版
      $120/月 + 设备 $599
      推荐指数：⭐⭐⭐（仅限特殊需求）
```

### 我的推荐组合

```
手机配置：
  实体卡槽 → 中国移动（保号，接国内电话/短信/验证码）
  eSIM 1   → Airalo（出国时激活当地套餐）
  eSIM 2   → 备用（长期出差时可加 Google Fi）

+ 小火箭保持运行（代理系列正篇的配置）

结果：
  在中国 → 实体卡上网 + 小火箭翻墙
  到国外 → eSIM 上网 + 实体卡接电话 + 小火箭分流
  
  全程不断联，全程能翻墙
```

## 小结

1. **eSIM 是焊在手机里的 SIM 芯片**，通过下载配置文件切换运营商，不用插拔卡。一台手机可以存 8+ 个 eSIM，同时激活 2 个。

2. **出国联网首选 Airalo eSIM**——出发前 App 买好，落地即用，$5 起。

3. **Google Fi 适合频繁出国**——一张卡全球 200+ 国家自动漫游，还送美国号码。

4. **Starlink 解决极端场景**——有天空就能上网，但贵。

5. **和代理系列配合**：物理层用 eSIM 解决联网，逻辑层用小火箭解决翻墙，两层都不断 = 全球无缝。
